# Референсы панелей управления Project Zomboid Dedicated Server

Сравнение для локальной панели на Windows: готовая установка Dedicated Server, несколько профилей, запуск и остановка из панели, основные настройки и просмотр модов. Сравнивались опубликованные руководства, README и скриншоты; приложения не устанавливались и не тестировались.

## Ближайшие примеры

| Приложение | Что документировано или видно | Что взять для нашего интерфейса |
| --- | --- | --- |
| PZServerLauncher | Windows-приложение с `Scan Imports` для поиска существующих серверов и отдельными профилями с собственными настройками и сохранениями ([README](https://github.com/Bentheck/PZServerLauncher)). На скриншоте видно список профилей слева и рабочую область выбранного сервера справа ([экран профилей](https://github.com/Bentheck/PZServerLauncher/blob/main/docs/images/readme/mods-and-maps.png)). | Список экземпляров и детали выбранного сервера в одном окне. Поиск в стандартной папке запускать автоматически, без обязательного мастера установки. |
| Zomboid Manager (Vuscoo) | Локальная Windows-панель использует указанные папку Dedicated Server, каталог данных и стартовый `.bat`. Поддерживает Start / Stop / Restart, отличает запуск процесса от готовности сервера, показывает Workshop ID и Mod ID. Её Config Profiles являются снимками настроек, а не подтверждением параллельного запуска ([README](https://github.com/Vuscoo/zomboidmanager)). | Поместить состояние и основные действия на один экран. В модах показывать данные выбранного профиля и не путать Workshop ID с Mod ID. |
| Zomboid Control Panel | Руководство для Windows описывает `Add Existing Server`, сканирование каталога данных, выбор серверной установки и проверку подключения по RCON ([руководство для Windows](https://github.com/fpsacha/zomboid-control-panel/blob/main/docs/install/windows.md)). Панель выводит несколько серверов и действия над каждым ([README](https://github.com/fpsacha/zomboid-control-panel)). | Разделить обнаружение профиля, возможность запустить его и возможность штатно остановить уже запущенный процесс. |
| PZ Manager | Демонстрация включает список профилей, визуальную форму серверных параметров, настройки песочницы, просмотр INI и отдельный экран управления сервером ([Showcase и FAQ](https://pz-manager.vercel.app/)). | Взять принцип короткой визуальной формы. Сырой редактор INI и удалённые рабочие пространства сейчас не нужны. |

При повторном открытии панель должна снова определить состояние каждого экземпляра. |

## Предлагаемый первый экран

Слева список найденных профилей и их статусы. Справа выбранный сервер: статус, «Запустить», «Остановить», диагностика, если действие недоступно, и вкладки «Настройки», «Песочница» и «Моды». Принудительная остановка отделена от обычной и доступна только для точно определённого процесса. Настройки, сохранённые во время работы, помечены как ожидающие перезапуска. Это рекомендация по дизайну, а не утверждённая спецификация.

## Что проверить отдельно

Список профилей или карточки нескольких серверов не доказывают, что два экземпляра из одной Windows-установки одновременно принимают игроков. Раздел официальной вики о нескольких экземплярах описывает Linux, а не Windows ([PZwiki](https://pzwiki.net/wiki/Dedicated_server)). Для проекта нужна отдельная проверка на целевой сборке: запустить два профиля, подтвердить доступность обоих, закрыть и снова открыть панель, штатно остановить один и убедиться, что второй остался доступен. Также нужно проверить обнаружение и штатную остановку экземпляра, запущенного вне панели.
