# Планирование первой версии PZ Server UI

Заметка фиксирует согласованные границы и варианты, которые ещё предстоит проверить или согласовать.

## Согласовано

- Одна существующая установка Project Zomboid Dedicated Server на Windows для нескольких именованных профилей. Панель не устанавливает сервер и не использует игровой клиент.
- Панель автоматически находит существующие профили в стандартном каталоге, в том числе сохранённые профили без мира. Два экземпляра должны иметь возможность работать одновременно. Закрытие панели не останавливает экземпляры.
- Запуск, штатная и отдельная принудительная остановка доступны из панели. Если у сервера, запущенного вне панели, не настроен RCON и штатная остановка недоступна, панель объясняет причину; не включает RCON и не перезапускает сервер за пользователя.
- При конфликте портов панель блокирует запуск, сообщает о конфликте и предлагает свободные порты. Действие «Применить порты и запустить» показывает старые и новые порты, после подтверждения сохраняет настройки только выбранного профиля и повторяет его запуск.
- Собственный запуск показывает «Запускается» до подтверждения готовности и «Работает» после него. Для процесса, запущенного вне панели, без подтверждения готовности отображается «Процесс запущен, готовность не подтверждена».
- Если штатная остановка не завершилась, панель сообщает об этом и предлагает повторить её или отдельно запросить принудительное завершение точно определённого процесса. Автоматического перехода к принудительной остановке нет.
- Моды только для просмотра. Основные настройки и небольшой набор параметров песочницы доступны для редактирования. Сохранение настроек во время сеанса не должно автоматически перезапускать сервер.
- При ошибке панель показывает краткую причину, если она известна, последние строки лога и ссылку «Открыть полный лог». Интерактивной консоли в первой версии нет.
- Если конфиг изменился вне панели после открытия формы, панель не перезаписывает его молча и не объединяет правки автоматически. Она предлагает перечитать файл, не стирая введённые в форме значения.
- Основной редактор включает отображаемое имя, лимит игроков, PvP и игровые порты. Пароль для входа, видимость сервера и настройки RCON в первую форму не входят.
- «Перезапустить» запускает новый сеанс только после подтверждённой штатной остановки предыдущего. Если остановка не удалась, панель не запускает второй процесс и не завершает первый принудительно.

## Стартовый набор песочницы

Проверить на отдельном тестовом профиле после сохранения и перезапуска:

| Поле | Проверка в игре |
| --- | --- |
| Стартовый набор (`StarterKit`) | Включить, зайти новым персонажем и проверить его инвентарь после появления. |
| Дополнительные очки черт (`CharacterFreePoints`) | Добавить, например, 10 очков и проверить разницу на экране создания персонажа. |
| Длительность игрового дня (`DayLength`) | Выбрать короткий день, например 15 минут, и проверить по игровым часам, как быстро идёт время после входа. |

Назначение полей описано в [PZwiki: Server settings](https://pzwiki.net/wiki/Server_settings). Точные допустимые значения и применение к существующему миру нужно проверить на целевой сборке; проверка первых двух параметров не должна требовать сброса основного мира или персонажа.

## Предложение для приёмки

- На одной Windows-установке из панели запустить два тестовых профиля и убедиться, что к обоим можно подключиться. Закрыть и снова открыть панель: оба сеанса остаются доступными, их состояние определяется повторно.
- Штатно остановить один профиль и подтвердить, что второй доступен. Отдельно проверить обнаружение профиля, запущенного вручную: с настроенным RCON он штатно останавливается, без рабочего RCON панель объясняет недоступность действия.
- Создать конфликт портов, подтвердить предложенную замену и убедиться, что панель меняет только выбранный профиль. После запуска проверить подключение по новым портам.
- На тестовом профиле проверить сохранение настроек без рестарта, явный перезапуск и три наблюдаемых параметра песочницы. Отдельно проверить, что внешнее изменение конфига не перезаписывается.
- Проверить обработку ошибки запуска и принудительную остановку только выбранного тестового сеанса. Не проверять аварийное завершение на основном мире.
