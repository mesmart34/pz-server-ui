# 15 — Добавить лимит игроков, PvP и игровые порты в редактор

**Что сделать:** Позволить администратору редактировать ещё три группы основных параметров выбранного сервера.

**Блокируется:** №14 «Безопасно изменить отображаемое имя».

**Статус:** ready-for-agent

- [ ] Форма читает и сохраняет лимит игроков, переключатель PvP и игровые порты выбранного экземпляра; недопустимые значения не записываются.
- [ ] При сохранении остальные параметры и соседние профили не изменяются; конфликт с ручной правкой файла обрабатывается как для отображаемого имени.
- [ ] Изменения сохраняются без автоперезапуска. Пароль входа, видимость и настройки RCON не появляются в редакторе.
