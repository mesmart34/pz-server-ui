# 07 — Восстановить управление после закрытия панели

**Что сделать:** Продолжить управление двумя сеансами, которые пережили полное закрытие панели.

**Блокируется:** №06 «Запустить два экземпляра одновременно».

**Статус:** ready-for-agent

- [ ] После закрытия приложения оба тестовых сеанса остаются доступны без службы Windows или процесса панели в трее.
- [ ] При повторном открытии панель определяет оба профиля и их фактические состояния, не запуская их повторно.
- [ ] Панель штатно останавливает выбранный сеанс после повторного открытия, а второй продолжает принимать игроков.
- [ ] Проверка пройдена на целевой сборке Windows с двумя тестовыми профилями. Это контрольная точка перед вторым этапом.
