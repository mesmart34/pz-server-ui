# 18 — Изменить и проверить настройки песочницы

**Что сделать:** Добавить три настройки песочницы, эффект которых можно быстро проверить в игре.

**Блокируется:** №14 «Безопасно изменить отображаемое имя» и №12 «Явно перезапустить экземпляр».

**Статус:** ready-for-agent

- [ ] Для выбранного профиля доступны стартовый набор, дополнительные очки черт и длительность игрового дня.
- [ ] Сохранение не перезапускает сеанс, не удаляет остальные параметры песочницы и не затирает внешние правки.
- [ ] После явного перезапуска тестового профиля у нового персонажа проверяются стартовый набор и очки черт; длительность дня проверяется по скорости игровых часов.
- [ ] Для проверки не сбрасываются основной мир и персонажи.
