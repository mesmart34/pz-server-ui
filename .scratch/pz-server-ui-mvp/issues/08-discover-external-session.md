# 08 — Обнаружить экземпляр, запущенный вручную

**Что сделать:** Показать в панели внешне запущенный сеанс под правильным существующим профилем.

**Блокируется:** №07 «Восстановить управление после закрытия панели».

**Статус:** ready-for-agent

- [ ] Сеанс тестового профиля, запущенный вручную до открытия панели, определяется без нового запуска.
- [ ] При точно определённом процессе без подтверждённой готовности показывается «Процесс запущен, готовность не подтверждена».
- [ ] Неоднозначный процесс не привязывается к произвольному профилю и не становится целью действий остановки.
