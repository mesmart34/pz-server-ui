# 03 — Запустить выбранный экземпляр

**Что сделать:** Дать администратору возможность запустить выбранный существующий профиль из панели без участия игрового клиента.

**Блокируется:** №02 «Показать существующие профили».

**Статус:** ready-for-agent

- [ ] Кнопка «Запустить» обращается к выбранной установке и именованному профилю, а не молча к профилю по умолчанию.
- [ ] При запуске отображается «Запускается», а повторное действие не создаёт второй сеанс того же экземпляра.
- [ ] Запуск не меняет конфиги других профилей и не запускает игровой клиент.
