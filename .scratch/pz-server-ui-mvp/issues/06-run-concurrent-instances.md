# 06 — Запустить два экземпляра одновременно

**Что сделать:** Подтвердить независимую работу двух сеансов из одной установки на целевой рабочей сборке Windows.

**Блокируется:** №05 «Штатно остановить один экземпляр».

**Статус:** ready-for-agent

- [ ] Из панели запускаются два тестовых профиля с отдельными настройками, мирами и неконфликтующими портами.
- [ ] Оба сеанса одновременно работают; игровой клиент может подключиться к каждому, пока второй тоже запущен.
- [ ] Штатная остановка одного тестового экземпляра не прерывает второй, который остаётся доступным.
- [ ] Номер проверенной сборки и фактический результат теста записаны; основной мир не используется.
