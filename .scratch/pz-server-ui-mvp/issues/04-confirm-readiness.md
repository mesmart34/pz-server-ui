# 04 — Подтвердить готовность сервера

**Что сделать:** Отличать создание серверного процесса от момента, когда сервер готов принимать игроков.

**Блокируется:** №03 «Запустить выбранный экземпляр».

**Статус:** ready-for-agent

- [ ] Статус «Работает» выставляется только после подтверждения готовности именно выбранного сеанса на целевой сборке Dedicated Server.
- [ ] Если процесс завершился до готовности, панель не выставляет «Работает» и показывает, что запуск не удался.
- [ ] Пока готовность не подтверждена, интерфейс не сообщает, что к серверу уже можно подключаться.
