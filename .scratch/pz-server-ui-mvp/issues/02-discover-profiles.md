# 02 — Показать существующие профили

**Что сделать:** Автоматически показать существующие профили в главном окне и дать администратору выбрать экземпляр.

**Блокируется:** №01 «Выбрать установку Dedicated Server».

**Статус:** ready-for-agent

- [ ] Именованные профили из стандартного каталога данных текущего пользователя появляются без ручного добавления, в том числе профиль без мира.
- [ ] Слева находится список профилей, справа отображаются данные выбранного экземпляра; переключение меняет контекст действий.
- [ ] Пустой каталог даёт понятное пустое состояние; обнаружение не создаёт и не меняет конфиги или миры.
