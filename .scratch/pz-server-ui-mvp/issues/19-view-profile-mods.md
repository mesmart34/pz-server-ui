# 19 — Показать моды выбранного профиля

**Что сделать:** Отобразить список модов из настроек выбранного экземпляра без действий редактирования.

**Блокируется:** №02 «Показать существующие профили».

**Статус:** ready-for-agent

**Порядок работ:** брать после проверки №07; это не техническая зависимость.

- [ ] При переключении профиля список соответствует его конфигу, а не каталогу всех установленных модов или фактически активным модам сеанса.
- [ ] Workshop ID и Mod ID отображаются как разные типы данных; пустой список показан явно.
- [ ] Просмотр не меняет конфиги, не скачивает моды и не меняет их порядок.
