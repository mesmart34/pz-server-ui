# 16 — Заблокировать запуск при конфликте портов

**Что сделать:** Предотвратить запуск выбранного профиля при обнаруженном конфликте портов и объяснить причину.

**Блокируется:** №06 «Запустить два экземпляра одновременно».

**Статус:** ready-for-agent

- [ ] Если второй тестовый профиль претендует на порт, уже занятый первым, запуск не начинается и панель называет конфликтующий порт.
- [ ] Работающий экземпляр остаётся доступным. Оба конфига после обнаружения конфликта не изменяются.
- [ ] На неконфликтующих тестовых профилях оба экземпляра по-прежнему запускаются.
