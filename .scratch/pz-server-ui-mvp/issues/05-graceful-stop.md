# 05 — Штатно остановить один экземпляр

**Что сделать:** Штатно завершить сеанс, запущенный из панели, с сохранением мира.

**Блокируется:** №04 «Подтвердить готовность сервера».

**Статус:** ready-for-agent

- [ ] «Остановить» посылает штатный запрос выбранному сеансу, не завершает процесс аварийно и не воздействует на другие процессы.
- [ ] Запрос и фактическая остановка различаются: статус «Остановлен» появляется только после подтверждения выхода процесса.
- [ ] Повторный запуск тестового экземпляра открывает его прежний мир.
