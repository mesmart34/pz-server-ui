# 01 — Выбрать установку Dedicated Server

**Что сделать:** В нативном приложении Windows на .NET 10 и .NET MAUI/XAML администратор выбирает папку одной существующей установки Dedicated Server.

**Блокируется:** нет, можно начинать сразу.

**Статус:** ready-for-agent

- [ ] Папка с подходящим серверным запуском принимается, выбор сохраняется между открытиями панели.
- [ ] Неверная папка отклоняется с объяснением; прежний корректный выбор не заменяется.
- [ ] Панель не устанавливает сервер и не открывает игровой клиент.
