# 14 — Безопасно изменить отображаемое имя

**Что сделать:** Дать возможность изменить отображаемое имя экземпляра через форму, не перезаписывая внешние правки.

**Блокируется:** №07 «Восстановить управление после закрытия панели».

**Статус:** ready-for-agent

- [ ] Сохранение меняет только отображаемое имя в выбранном профиле. Имя самого профиля и остальные параметры сохраняются.
- [ ] Если конфиг изменился с момента открытия формы, панель блокирует перезапись и предлагает перечитать файл, не теряя введённое значение и не объединяя правки автоматически.
- [ ] Сохранение не перезапускает работающий сеанс и помечает изменение как ожидающее перезапуска.
