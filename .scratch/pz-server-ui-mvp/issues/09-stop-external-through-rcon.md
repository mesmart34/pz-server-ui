# 09 — Штатно остановить внешний экземпляр через RCON

**Что сделать:** Остановить найденный внешний сеанс, если его RCON уже настроен и доступен.

**Блокируется:** №08 «Обнаружить экземпляр, запущенный вручную».

**Статус:** ready-for-agent

- [ ] При рабочем RCON штатно завершается только выбранный тестовый экземпляр; повторный запуск открывает прежний мир.
- [ ] Если RCON выключен или недоступен, панель объясняет невозможность штатной остановки и не показывает «Остановлен».
- [ ] Панель не включает RCON, не меняет конфиг или сетевые настройки, не перезапускает сервер и не выводит пароль в диагностику.
