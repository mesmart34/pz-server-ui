# 11 — Принудительно завершить выбранный сеанс

**Что сделать:** Дать отдельное аварийное действие для точно определённого сеанса, когда штатная остановка не удалась или недоступна.

**Блокируется:** №10 «Повторить неудачную штатную остановку».

**Статус:** ready-for-agent

- [ ] Подтверждение называет экземпляр и предупреждает о риске потери несохранённого прогресса; отмена ничего не завершает.
- [ ] После подтверждения целевой процесс проверяется повторно; при неоднозначности или изменении процесса завершение не выполняется.
- [ ] На тестовых сеансах завершается только выбранный процесс. Второй экземпляр и игровой клиент не затрагиваются.
