# 13 — Показать диагностику неудачного запуска

**Что сделать:** Объяснить неудачный запуск в интерфейсе и дать доступ к журналу выбранного сеанса.

**Блокируется:** №04 «Подтвердить готовность сервера».

**Статус:** ready-for-agent

**Порядок работ:** брать после проверки №07; это не техническая зависимость.

- [ ] При сбое показаны известная причина и последние доступные строки журнала выбранного сеанса; неизвестная причина не подменяется догадкой.
- [ ] При наличии журнала доступно действие «Открыть полный лог»; при отсутствии интерфейс это объясняет.
- [ ] Диагностика не раскрывает пароль RCON и не показывает журнал соседнего экземпляра вместо выбранного.
