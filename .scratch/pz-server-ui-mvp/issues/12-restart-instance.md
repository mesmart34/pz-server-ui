# 12 — Явно перезапустить экземпляр

**Что сделать:** Добавить команду «Перезапустить», которая штатно останавливает сеанс и затем запускает тот же профиль.

**Блокируется:** №07 «Восстановить управление после закрытия панели».

**Статус:** ready-for-agent

- [ ] Новый сеанс запускается только после подтверждения выхода предыдущего процесса и использует тот же профиль.
- [ ] Если штатная остановка не удалась или недоступна, перезапуск прекращается без запуска второго процесса и без принудительного завершения первого.
- [ ] На двух тестовых экземплярах перезапуск выбранного не прерывает соседний.
