# 10 — Повторить неудачную штатную остановку

**Что сделать:** Дать понятный результат и возможность повторить запрос, если выбранный процесс не завершился.

**Блокируется:** №09 «Штатно остановить внешний экземпляр через RCON».

**Статус:** ready-for-agent

- [ ] При неудачной штатной остановке панель сообщает, что завершение не подтверждено, и не показывает «Остановлен».
- [ ] Администратор может повторить штатную остановку, если канал по-прежнему доступен; повтор обращается только к подтверждённому сеансу.
- [ ] Для сеансов панели и внешних сеансов отсутствует автоматический переход к принудительному завершению.
