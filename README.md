# PZ Server UI

Локальное приложение Windows для управления существующими выделенными серверами Project Zomboid. Панель будет находить профили из одной установки Dedicated Server, запускать и останавливать выбранный экземпляр, редактировать основные настройки и показывать список модов.

Стек: .NET 10 и .NET MAUI с нативным XAML. Реализация ещё не начата.
