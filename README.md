# PZ Server UI

Локальное приложение Windows для управления существующими выделенными серверами Project Zomboid. Стек: .NET 10 и .NET MAUI с нативным XAML.

## Что уже реализовано

Можно выбрать папку существующей установки Dedicated Server. Панель проверяет наличие одного из стандартных файлов запуска (`StartServer64.bat`, `StartServer64_nosteam.bat` или `StartServer32.bat`) и запоминает выбор.

Список профилей автоматически читается из `%USERPROFILE%\Zomboid\Server`. Профиль отображается, даже если папка его мира ещё не появилась. Выбери профиль слева, чтобы увидеть справа его файл настроек и папку мира. Кнопка «Обновить» повторно читает каталог.

«Запустить» передаёт имя выбранного профиля штатному лаунчеру Dedicated Server. Поддерживается однострочная команда запуска `zombie.network.GameServer` с передачей `%1 %2` или `%*`. Если параметры не передаются или профиль жёстко задан в скрипте, запуск отменяется. Панель не запускает игровой клиент и не переписывает конфиги. Повторный запуск того же профиля блокируется, пока его лаунчер не завершится; если скрипт остаётся на `PAUSE` после остановки сервера, закрой окно лаунчера перед повторным запуском.

Панель показывает «Работает» после строки `*** SERVER STARTED ****` в сетевом логе того сеанса, который она запустила. До сигнала она показывает ожидание, а если лаунчер завершился раньше, сообщает об ошибке. Для каждого запуска создаётся отдельный временный журнал в `%LOCALAPPDATA%\PzServerUi\sessions`; общий лог игры не используется. Это не проверка доступности порта извне и не распространяется на ранее или вручную запущенные серверы.

## Сборка и проверка

Для сборки на Windows нужны .NET 10 SDK и workload `maui-windows`. Установить workload на машине разработки:

```powershell
dotnet workload install maui-windows
```

Собрать и запустить приложение:

```powershell
dotnet build
dotnet run --project src/PzServerUi
```

Проверить сценарии выбора установки можно без MAUI и установки игры:

```powershell
dotnet run --project tests/PzServerUi.Application.Tests
```
